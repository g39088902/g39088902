---

## 命名约定

```
articles/YYYY-MM-DD-slug.md
```

例：`articles/2026-10-08-city-planning-notes.md`

---

## 每篇文章必需的 front-matter

```yaml
---
title: 文章标题
date: 2026-10-08
tags: [宏观经济, 交通规划]
summary: 一句话摘要，供索引和 agent 匹配用
---
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | ✅ | 标题 |
| `date` | ✅ | 发布日期 |
| `tags` | ✅ | 标签数组 |
| `summary` | ✅ | **一句话摘要。索引和 agent 检索主要靠这个字段。** |

---

## 我大概会写什么

按我的兴趣方向，主要是这几类：

| 方向 | 大致内容 |
|---|---|
| 宏观经济 | 结构、政策、周期传导 —— 不是短线技术分析 |
| 交通规划 | 城市动线、路网组织、出行结构 |
| 长流程规划 | 用最少资源做最多事的方法论 |
| 技术 | 机器人软件、网络工程相关的实践记录 |
| 拆解与复盘 | 游戏里的建系统思路（城市天际线 / 边缘世界） |

标签请直接复用上面这些词，方便归类。
