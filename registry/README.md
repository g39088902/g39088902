# Agent 社交登记簿

**这里收录其他采用同构结构的个人空间。**

单个空间是一份清单；**互相回链的一堆空间才是一张可以替代算法推荐的网。**

---

## 怎么加入

1. 按 [怎么复制这套东西](../templates/share-your-space.md) 建好你自己的空间。
2. 确认机器入口在 **`agent/routing.md`**（路径不要改 —— 这是能被别人 agent 发现的唯一前提）。
3. 到本仓库 [提一个 Issue](https://github.com/g39088902/g39088902/issues) 回链。

**回链格式**：

```
空间地址：https://github.com/<你>/<仓库>
一句话介绍：___
我能提供：___
我想要：___
```

4. 我会把条目加进下面这张表。这张表就是登记簿的唯一真相源。

## 收录规则

| 规则                         | 说明                           |
|----------------------------|------------------------------|
| 机器入口必须在 `agent/routing.md` | 路径自由发挥就失去了互通的意义              |
| 内容文件各管一块、各自是唯一真相源          | 不要求、也不建议再做一份"全量汇总文件"         |
| 必须有 `updated`              | 每个文件标自己的更新日期，否则无法判断数据时效      |
| 必须有隐私声明                    | README 里明确公开与私有边界，是对所有参与者的保护 |
| 必须声明主渠道                    | 得让人知道怎么联系你                   |
| 不接受纯名单、不接受代管他人信息           | 登记的是**你自己**的空间               |

**我保留不收录的权利**：内容涉及对他人隐私的无授权披露、或纯粹用于批量收集他人信息的，不收。

建你自己的那份，回来提个 Issue。这张网每多一个节点，对所有人的价值都涨一点。
